Q)How did you manage database interactions in the Shipping module?

Answer: I used Hibernate as the ORM framework to manage interactions with PostgreSQL. We used JPA annotations to map 
Java objects to database tablesand wrote custom queries using JPQL for more complex operations. For instance, 
in the Stock submodule, we frequently checked inventory levels and used batch processing for 
bulk updates to ensure database efficiency.


Q)Can you explain a challenge you faced while working on the Shipping module and how you resolved it?

Answer: (1) One challenge I faced was ensuring data consistency when updating stock levels, order status, 
and product details during order processing. 
To resolve this,we implemented Transaction Management used Spring’s @Transactional annotation to manage transactions. 
This ensured that all operations were either
completed successfully or rolled back if any step failed, preventing partial updates and maintaining data integrity.

(2)challenge we faced was handling bulk order processing during peak times, which caused performance issues. 
We optimized this by introducing batch processing,using Hibernate’s
bulk operations, and fine-tuning the SQL queries to reduce database load. 
We also adjusted connection pooling and caching strategies for better performance.

Q) What is flow of application?
In a Spring Boot application, everything starts from the main application class, which sets up the project
 and gets it running. When a user sends a request, it goes to a controller that handles it. 
 The controller calls a service to do the main work or business logic. The actual work is done 
 in the service implementation, which might also get data from a database. Once the service finishes, it sends
 the results back to the controller, which then prepares the final response and sends it back to the user. 
 This setup keeps things organized and makes it easier to manage the application.

Q)How you configure Actuator in your application?
To set up Spring Boot Actuator for health checks, I would take a few simple steps. First, I would add the 
Spring Boot Actuator dependency to my project.This is done by including a line in the pom.xml file. 
Next, I would configure the application settings in the application.properties 
file to enable the health check endpoint. I would specifically add a line to expose the /actuator/health endpoint 
so I can access it.After that, I would run the 
application and check the health status by going to the /actuator/health URL in my browser or using a tool like Postman. 
This endpoint gives me a quick overview of whether the application is running properly.Finally, if necessary, 
I could add security measures to restrict access to these endpoints, ensuring only authorized users can check the 
health status.

Q)Explain how you set up CI/CD using Jenkins in your project.

Answer: We set up Jenkins for continuous integration and delivery (CI/CD) to automate the build, testing,
and deployment processes. Whenever code was pushed to Git, Jenkins would trigger a pipeline to:
Pull the latest code.
Run unit tests and integration tests using JUnit.
Build the application using Maven.
Deploy the built package to the test environment and, after approval, to the production environment.

Q)How did you integrate Jenkins into your development process?

Answer: Jenkins was used as part of our CI/CD pipeline to automate testing and deployments. 
I set up pipelines that automatically ran unit tests and integration tests whenever new code was pushed to the repository. 
This ensured that the code was always in a deployable state. If any issues were found, Jenkins notified the team, 
and we could resolve the problem quickly before it reached production.
